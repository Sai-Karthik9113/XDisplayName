# Full Name Display React App

This project is a simple React app that allows users to input their first name and last name, then displays the full name after submitting the form. It demonstrates the use of React hooks (`useState`) for managing form inputs and state.

## Features
- **First Name and Last Name Input**: Users can enter their first and last names.
- **Full Name Display**: After submitting the form, the app displays the full name in a formatted way.
- **Form Submission**: The form is submitted using the submit button, and the page does not reload due to `event.preventDefault()`.

## Technologies Used
- **React**: Used to create the user interface and manage the app's state.
- **JavaScript**: Handles the form logic and manages the full name display.
- **CSS**: Basic styling for layout.

## How to Run the Project Locally

1. Clone the repository:
   ```

   git clone https://github.com/Sai-Karthik9113/XDisplayName.git
   ```

2. Navigate to the project directory:
   ```

   cd full-name-display-react
   ```

3. Install dependencies:
   ```

   npm install
   ```

4. Start the development server:
   ```

   npm start
   ```

5. Open the app in your browser at `http://localhost:3000`.
